# PiCoCo

An RP2350 cartridge for the Tandy Color Computer: a ROM emulator plus a DriveWire Becker port. Hardware is KiCad under `PiCoCo/`, firmware under `firmware/`, design docs under `docs/`.

## Read first

- `CONTEXT.md`: the vocabulary. Use its terms in issues, tests and commit messages.
- `docs/adr/`: before touching the bus buffers, the /OE decode, GPIO assignments, module power, the halt hold, the board outline, or anything core1 runs. Each is one paragraph; a change that contradicts one is wrong until the ADR is superseded.
- `docs/hardware-design.md`, `docs/firmware-architecture.md`, `docs/kicad-workflow.md`: the design, read the section for the area you are changing.
- `firmware/README.md`: build, flash and console commands.
- `docs/superpowers/`: the spec and plan archive from the previous workflow, read-only. New specs go to GitHub issues.

## Hard rules

- The schematic and two library parts are generated by `tools/gen_schematic.py` (ADR 0010). Edit the `pin_nets` dicts and regenerate; then in KiCad close and reopen the schematic and run Update PCB from Schematic with "delete footprints with no corresponding symbol".
- `PiCoCo/PiCoCo.kicad_pcb` is hand-routed and authoritative. Running `tools/place_pcb.py` on it destroys the routing.
- Moving a GPIO means editing `docs/firmware-architecture.md` in the same change (ADR 0003).
- Code that core1 executes stays `BUS_HOT` (ADR 0008); only core1 writes the Becker entries of the bus table (ADR 0009).
- The `*.v1-backup` files under `PiCoCo/` are reference snapshots. Keep them out of commits you stage.

## Sandbox quirks

- `kicad-cli pcb drc` crashes inside the Bash sandbox; run it sandbox-disabled, with `PiCoCo.kicad_pro` beside the board file or it silently uses default rules. ERC, render and Gerber export work sandboxed. `tools/gen_fab.sh` skips DRC on purpose.
- `tools/gen_breakout.py` needs KiCad's bundled Python (it drives pcbnew).
- Flashing and the console from the sandbox: `firmware/tools/flash.sh` and `firmware/tools/pconsole.py`; picotool cannot see the device.
